Product Requirements Document (PRD)

Sistem Penerimaan Tamu Sekolah

1. Ringkasan Proyek

Aplikasi berbasis web untuk mendigitalisasi proses pencatatan dan penerimaan tamu di lingkungan sekolah. Sistem ini akan mencatat identitas, mengambil foto wajah tamu, mengumpulkan data kunjungan, dan mencetak kartu akses pengunjung secara instan.

2. Tujuan Utama

  • Meningkatkan keamanan sekolah dengan memverifikasi setiap tamu yang masuk.
  • Mempercepat proses registrasi di meja resepsionis atau pos satpam.
  • Menyediakan pangkalan data historis kunjungan yang rapi dan mudah dilacak.

3. Alur Pengguna (User Flow)

  1. Akses Awal: Pengguna membuka situs dan dihadapkan pada halaman Login.
  2. Autentikasi: Pengguna masuk menggunakan kredensial yang sah.
  3. Verifikasi Visual: Sistem meminta izin akses kamera dan mengambil foto wajah tamu.
  4. Pengisian Data: Tamu atau staf melengkapi formulir detail kunjungan.
  5. Konfirmasi & Cetak: Sistem menampilkan ringkasan data dan foto, dilengkapi tombol untuk mencetak Kartu Pengunjung.

4. Spesifikasi Fitur Utama

A. Halaman Login

Fitur: Form input Username/Email, Password, dan tombol Submit.

Fungsi: Autentikasi awal untuk membatasi akses aplikasi hanya bagi staf yang berwenang.

B. Pengambilan Foto

Fitur: Integrasi API Kamera (Webcam), antarmuka viewfinder, tombol ambil foto, dan retake.

Fungsi: Menangkap wajah tamu secara real-time untuk dicetak pada kartu ID pengunjung.

C. Formulir Registrasi

  • Nama & Instansi: Input teks.
  • Tujuan Kunjungan: Dropdown (Rapat, Bertemu Siswa/Guru, dll).
  • Jadwal: Komponen Date & Time picker otomatis.
  • Pihak Dituju: Input teks dan numerik dengan validasi.

D. Konfirmasi & Cetak

Fitur: Pratinjau (Preview) ID Card pengunjung.

Fungsi: Menggunakan fungsi cetak pada peramban web (browser) untuk mencetak ID tamu langsung ke printer.

5. Pedoman Audit Keamanan & Bug (Security Review)

Sebagai bagian dari proses hybrid vibe coding, setelah kode di-generate, audit manual difokuskan untuk mencari celah pada titik-titik krusial berikut:

  • Bypass Autentikasi: Memastikan halaman form dan cetak tidak dapat diakses paksa melalui URL tanpa sesi login.
  • Izin Perangkat (Kamera): Menyediakan skenario fallback yang aman tanpa menyebabkan aplikasi crash apabila akses kamera ditolak.
  • Validasi Input (XSS/SQLi): Melakukan sanitasi ketat pada input teks (nama, instansi) agar terhindar dari injeksi *script* berbahaya.
  • Keamanan File Upload: Memastikan pengambilan gambar hanya menyimpan format yang aman (.jpg/.png) ke server/repositori.
